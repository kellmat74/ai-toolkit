# Note-Taking Skills Umbrella

This skill serves as an umbrella for various note-taking tools and workflows, including Obsidian vault management.

## Subskills

- **obsidian**: Read, search, create, and edit notes in the Obsidian vault.

Each subskill has its own detailed documentation. Use `skill_view(<subskill-name>)` to see specific instructions.

## Usage

When working with note-taking tasks, load this skill to access the relevant subskills. The umbrella skill provides guidance on choosing the right subskill for your note-taking workflow.
