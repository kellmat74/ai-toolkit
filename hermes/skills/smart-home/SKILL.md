# Smart-Home Skills Umbrella

This skill serves as an umbrella for various smart-home tools and workflows, including Philips Hue lighting control.

## Subskills

- **openhue**: Control Philips Hue lights, scenes, rooms via OpenHue CLI.

Each subskill has its own detailed documentation. Use `skill_view(<subskill-name>)` to see specific instructions.

## Usage

When working with smart-home tasks, load this skill to access the relevant subskills. The umbrella skill provides guidance on choosing the right subskill for your smart-home workflow.
