# Social-Media Skills Umbrella

This skill serves as an umbrella for various social-media tools and workflows, including X/Twitter interaction via CLI.

## Subskills

- **xurl**: X/Twitter via xurl CLI: post, search, DM, media, v2 API.

Each subskill has its own detailed documentation. Use `skill_view(<subskill-name>)` to see specific instructions.

## Usage

When working with social-media tasks, load this skill to access the relevant subskills. The umbrella skill provides guidance on choosing the right subskill for your social-media workflow.
